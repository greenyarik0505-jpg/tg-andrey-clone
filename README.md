# Telegram Business · панель автоответов

Бот отвечает в выбранных личных чатах подключённого аккаунта в стиле Андрея. В каждом сообщении есть пометка «🤖 Андрей». Администратор управляет системой, подключённый аккаунт принадлежит Андрею. Панель показывает эти роли отдельно, состояние подключения, права, подтверждения, настройки провайдера и ошибки ответов.

## Локальный запуск

Требуется Python 3.11 или новее.

```powershell
python -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
python run.py
```

Создавайте `.env` из примера при первой настройке. Для работы Telegram укажите `BOT_TOKEN` и `ADMIN_ID`. `BUSINESS_USER_ID` можно оставить пустым: администратор подтвердит подключение кнопкой в боте.

Для локального просмотра задайте случайный `LOCAL_ADMIN_TOKEN` длиной не менее 24 символов и откройте `http://127.0.0.1:8080`. Введите этот токен в форме. Для ответов укажите Base URL, ID модели и при необходимости ключ своего OpenAI-совместимого провайдера в Mini App.

## Подключение через «Автоматизацию чатов»

1. Включите Chat Access Mode для бота в BotFather.
2. На нужном аккаунте отправьте боту `/connect`. Кнопка ведёт в настройки Telegram. В разделе «Автоматизация чатов» добавьте бота и разрешите отвечать в выбранных чатах. Если клиент не открывает настройки по ссылке, откройте их вручную. Premium для подключения не нужен.
3. Задайте `WEBAPP_URL` с публичным HTTPS адресом и откройте Mini App через `/start` от имени `ADMIN_ID`.
4. Нажмите «Подтвердить аккаунт» в уведомлении бота или откройте `/business` с аккаунта администратора. В новых чатах, которые Telegram разрешил боту, автоответы работают сразу. Переключатели существующих чатов доступны в Mini App.

Бот собирает серию сообщений с интервалом до двух секунд и отвечает на неё вместе. Задержка первого ответа по умолчанию от 6 до 14 секунд в зависимости от длины текста, плюс время генерации. Бот обновляет индикатор «печатает…» в течение задержки. Изменение настроек, пауза, отключение чата, ручной ответ владельца и новые входящие сообщения отменяют готовящийся ответ. Отключённые чаты видны по метаданным, но бот не записывает в них новые тексты.

## Команды администратора

- `/start`, `/status` — панель и статистика.
- `/connect` — переход в настройки Telegram для владельца аккаунта.
- `/business` — подключение аккаунта.
- `/test текст` — пробный ответ.
- `/pause`, `/unpause` — общая пауза.
- `/custom URL модель [ключ]` — подключить любой HTTP(S) адрес OpenAI-совместимого сервера. Можно указать Base URL с путём `/v1` или полный адрес `/v1/chat/completions`. Локальный Ollama доступен по адресу `http://127.0.0.1:11434/v1`, если он запущен на том же компьютере, что и бот.

Бот передаёт выбранному провайдеру до 12 недавних сообщений из активного подключения. Стиль Андрея настроен по экспорту из 16 492 сообщений и PDF-портрету. В код включены короткие речевые образцы и описание стиля. Полный архив и PDF при запуске не загружаются.

На Render настройки, привязка, история и очередь обновлений хранятся в Cloud Firestore проекта `andrey-chat-36a3dd`, база `bot-state` во Франкфурте. Сервер использует отдельный сервисный аккаунт. Ключи провайдера и содержимое входящей очереди шифруются Fernet. Webhook подтверждает обновление после записи в базу. Незавершённая обработка восстанавливается после перезапуска, повторы обновлений отсекаются.

Без `FIREBASE_PROJECT_ID` используется локальная SQLite для разработки.

Проверки механики запускаются командой `.venv/Scripts/python.exe -m unittest discover -s tests -v`. Интеграционная проверка Firestore включается переменными `FIRESTORE_TEST_PROJECT`, `FIRESTORE_TEST_DATABASE` и `FIRESTORE_TEST_CREDENTIALS`. Она использует временный раздел базы и удаляет проверочные данные.

Для сервера и обновления существующей установки см. [DEPLOY_INSTRUCTIONS.md](DEPLOY_INSTRUCTIONS.md).
